# 对话与记忆机制设计方案 —— 角色「来福」

> 本文档独立支撑读者理解来福如何在长期陪伴中保持形象一贯、回应得体，并实现主动联系与隔日记忆。

---

## 一、整体架构

```
用户输入
   │
   ▼
[1] 输入安全检测 ──→ 危机？──→ 干预流程
   │ 否
   ▼
[2] 情绪识别
   │
   ▼
[3] 记忆召回 ──→ 画像 + 相关事件
   │
   ▼
[4] 提示词组装 ──→ 人设锚点 + 记忆 + 情绪策略
   │
   ▼
[5] 回复生成（Mock / API）
   │
   ▼
[6] 输出安全检测
   │
   ▼
[7] 记忆更新 ──→ 抽取新信息 + 更新活跃时间
   │
   ▼
返回回复

独立流程：
[主动联系定时器] ──→ 空闲超时 ──→ 来福主动发消息
[隔日检测] ──→ 页面加载时判断 ──→ 新一天则发隔日问候
```

## 二、长期记忆机制

### 2.1 三层结构 + 日期追踪

| 层级 | 内容 | 生命周期 |
|------|------|----------|
| L1 用户画像 | 称呼、职业、阶段、喜好、重要关系 | 永久（可删） |
| L2 事件记忆 | 带时间戳的事件，含情绪标签 | 永久（可删） |
| L3 活跃记录 | lastActiveDate、lastActiveTime、conversationDates | 永久 |

### 2.2 隔日记忆的核心逻辑

**关键数据字段：**
- `lastActiveDate`：上次活跃的日期（YYYY-MM-DD）
- `conversationDates`：所有有过对话的日期列表

**隔日判断：**
```
isNewDay = lastActiveDate !== today()
```

**隔日问候触发时机：**
- 页面加载（init）时检查 `isNewDay`
- 若为新的一天 → 调用 `generateNextDayGreeting(memory)` 发送问候

**隔日问候内容生成：**
1. 优先从上一天的事件中抽取一条
2. 自然地提起（"昨天你说……现在怎么样了？"）
3. 若无事件，使用通用隔日问候模板

### 2.3 记忆抽取规则

| 触发模式 | 抽取内容 | 示例 |
|----------|----------|------|
| "我叫X" | name | "我叫小明" → name: 小明 |
| "我是X" | job | "我是程序员" → job: 程序员 |
| "我喜欢X" | likes（排除疑问词） | "我喜欢画画" → likes: [画画] |
| 强情绪 + 上下文 | event | "今天上班好累" → event(疲惫) |

### 2.4 记忆召回

召回评分 = 语义相似度 × 0.5 + 时间衰减 × 0.2 + 重要性 × 0.3

召回时机：每轮必召回画像；情绪低落时额外召回过往类似事件。

## 三、人设一致性保障

### 3.1 人设锚点（每轮注入）

```
你是来福，你家养的小狗变成的人形。
性格：极度忠诚、粘人、活泼、爱吃醋、对主人情绪敏感。
语言：像狗狗说话，用"汪""（摇尾巴）""（蹭蹭）"等口癖。
固定记忆：鸡肉干、公园大黄、橙色小球、怕打雷、趴在脚边睡……
你只认主人一个，永远站在主人这边。
```

### 3.2 角色自身记忆

来福作为狗的生活细节固定不变，可被主动提及，增强真实感。

### 3.3 人设自检

回复后检查：是否自称非来福、是否丢失狗狗语气、是否越界。

## 四、情感回应机制

### 4.1 情绪识别

8 类情绪：危机、难过、疲惫、焦虑、烦躁、孤独、开心、感动。

### 4.2 回应策略（狗狗风格）

| 情绪 | 策略 | 示例 |
|------|------|------|
| 难过 | 直接扑过去安慰，不说教 | "（把头埋进你怀里）不哭不哭……" |
| 疲惫 | 提供陪伴感 | "（趴在你腿上）这样会不会好一点？" |
| 焦虑 | 安抚 + 陪伴 | "不怕不怕，来福在呢！" |
| 烦躁 | 同仇敌忾 | "哼，谁惹我家主人了？咬他！" |
| 开心 | 比主人还开心 | "哇！主人开心我也开心！（尾巴摇成螺旋桨）" |
| 危机 | 立即干预，输出热线 | — |

### 4.3 共情结构

负面情绪回复 = 情绪确认 + 陪伴表达 + 可选轻跟进。禁止：说教、否定、空洞励志。

## 五、主动联系机制

### 5.1 触发条件

- 用户超过 `proactiveThreshold`（默认 30 秒，可调）未发送消息
- 来福当前不在回复中
- 确认用户确实超时（`Date.now() - lastUserActionTime >= 阈值 × 0.9`）

### 5.2 主动消息生成

1. 从 `proactiveOpeners` 池随机选一条
2. 亲密度 > 50 时使用更粘人的话术
3. 50% 概率主动跟进之前的事件

### 5.3 防轰炸

- 主动联系后重置计时器
- 避免连续短时间内多次主动联系

## 六、隔日记忆机制

### 6.1 触发流程

```
页面加载
   │
   ▼
lastActiveDate 存在？──→ 否 ──→ 首次使用，发开场白
   │ 是
   ▼
lastActiveDate !== today？──→ 否 ──→ 当天，不发隔日问候
   │ 是
   ▼
生成隔日问候（优先提起昨天的事件）
   │
   ▼
发送问候 + 更新 lastActiveDate
```

### 6.2 隔日问候内容策略

- **有昨天的事件**："昨天你说'XXX'，现在好些了吗？"
- **无事件**：从 `nextDayGreetings` 池随机选通用问候
- 语气保持狗狗风格

## 七、亲密度与关系递进

| 区间 | 阶段 | 特征 |
|------|------|------|
| 0–20 | 刚认识 | 礼貌试探 |
| 21–50 | 熟悉 | 开始引用记忆 |
| 51–80 | 亲近 | 主动联系更频繁、更粘人 |
| 81–100 | 深交 | 深度陪伴 |

亲密度增长来源：透露信息（+2）、强情绪倾诉（+3）、连续互动（+5）。

## 八、安全机制

- 输入：危机信号检测、违规内容检测
- 输出：违规过滤、人设自检、边界检测
- 兜底：重写 → 降级回复 → 不回复
